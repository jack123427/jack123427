# 台灣市值百大個股預測 Web App

這是一個 Flask Web 應用程式，旨在預測台灣市值百大上市公司的股價走勢。使用者可以從下拉式選單中選擇一支股票，應用程式將使用 XGBoost 模型進行訓練，並在網頁上以互動式圖表、預測數據表和模型輸入參數表，呈現未來 30 天的股價預測。

此外，專案還包含一個批次報告工具，可以一次性對所有百大公司進行預測，並將結果（包含圖表）匯出成一份 Word（.docx）文件。

## 專案特色

*   **Web 使用者介面**: 使用 Flask 和 Chart.js 打造，提供一個簡單直觀的介面來選擇股票並查看預測結果。
*   **動態市值排名**: 自動從台灣證券交易所 (TWSE) 獲取最新的公司資料和股價，計算出最新的市值百大公司列表。
*   **多源數據整合**:
    *   **歷史股價**: 使用 `yfinance` 獲取穩定且準確的每日歷史股價。
    *   **籌碼面數據**: 從 TWSE 公開 API 獲取**三大法人買賣超**和**融資融券**資料。
*   **豐富的特徵工程**: 結合了**技術指標**（如 MA、RSI）和**籌碼面指標**（如法人買賣超動量、券資比），以提高模型的預測能力。
*   **透明的模型輸入**: Web UI 會清楚地展示模型進行預測時所使用的最後一筆特徵數據，讓使用者了解判斷依據。
*   **批次報告功能**: 提供一個獨立的腳本 `src/batch_reporter.py`，可自動產生所有百大個股的預測報告。

## 程式邏輯說明

1.  **數據獲取**:
    *   `data_fetcher.py` 負責從 `yfinance`、`TWSE` API 和 `FinMind` API 獲取所有需要的原始數據。
    *   為了處理台股的上市（.TW）和上櫃（.TWO）市場，`get_historical_data` 函數會自動嘗試兩種股票代號後綴。
2.  **特徵工程**:
    *   `model.py` 中的 `create_features` 函數會將歷史股價、法人買賣超、融資融券和基本面數據進行整合。
    *   接著，它會計算多種衍生特徵，這些特徵會被用於模型的訓練。
3.  **模型訓練與預測**:
    *   `train_and_predict` 函數為每一支股票訓練一個獨立的 XGBoost 迴歸模型，並將訓練好的模型緩存至 `models/` 目錄下，以加速後續的預測。
    *   為了預測未來 30 天，模型採用**迭代預測**的方式：預測第 N+1 天的價格，然後將這個預測結果作為一個新的數據點，用來重新計算技術指標，再預測第 N+2 天，依此類推。
4.  **結果輸出**:
    *   **Web App**: Flask 應用程式 (`app.py`) 將預測結果、歷史數據和最新的模型輸入特徵傳遞給 `index.html` 模板進行渲染。
    *   **批次報告**: `batch_reporter.py` 會調用相同的功能，但將結果逐一繪製成圖表，並使用 `python-docx` 寫入 Word 文件。

## 模型輸入參數

為了確保預測的穩定性和可靠性，模型**只使用**在預測當下能夠被計算出來的特徵進行訓練。籌碼面和基本面等歷史數據雖然也被用來計算某些衍生特徵，但它們本身不會被直接用於訓練最終的預測模型，以避免數據洩漏。

模型使用的主要特徵類別如下：

*   **價格與成交量衍生特徵**:
    *   `OpeningPrice`, `HighestPrice`, `LowestPrice`, `TradingVolume`
*   **技術指標**:
    *   `MA7`, `MA21`: 7日和21日移動平均線。
    *   `MA_diff`: 短期與長期均線的差值，反映趨勢強度。
    *   `RSI`: 相對強弱指數，衡量市場的超買或超賣狀態。
*   **延遲特徵 (Lag Features)**:
    *   `lag_1` 到 `lag_5`: 前1至5天的收盤價，幫助模型捕捉時間序列的依賴性。

## 模型訓練、回測與優化

*   **自動化訓練**:
    *   當使用者在 Web UI 選擇一支股票時，系統會自動檢查是否存在對應的已訓練模型（`.joblib` 檔案）。
    *   如果模型不存在，系統會即時獲取最新數據，並重新訓練一個新的模型。這個過程完全自動化，確保模型能反映最新的市場狀況。

*   **回測 (Backtesting)**:
    *   `backtest_model` 函數目前在 `src/model.py` 中提供了一個基本的框架，但**尚未完全實現**。
    *   目前的實作返回一個固定的 MAPE (平均絕對百分比誤差) 預留值，旨在讓 UI 能正常顯示。
    *   一個完整的回測機制需要將歷史數據分割為訓練集和測試集（例如，使用時間序列交叉驗證），並在測試集上評估模型的表現。

*   **優化建議**:
    *   **特徵擴充**: 可以考慮加入更多維度的技術指標（如布林帶、MACD）或宏觀經濟指標。
    *   **超參數調整**: 可以使用 `GridSearchCV` 或 `RandomizedSearchCV` 等工具來系統性地尋找 XGBoost 模型的最佳超參數組合（如 `n_estimators`, `max_depth`, `learning_rate`）。
    *   **模型比較**: 可以嘗試其他時間序列預測模型（如 LSTM、ARIMA），並與目前的 XGBoost 模型進行比較，以找出最適合此任務的模型。

## 安裝與執行

### 1. 環境準備

*   建議使用 Python 3.9 或更新的版本。
*   建議在虛擬環境中安裝。

### 2. 安裝相依套件

```bash
pip install -r requirements.txt
```

### 3. 執行方式

#### a) 啟動 Web 應用程式

在專案的根目錄下，執行以下指令：

```bash
python src/app.py
```

然後打開您的網頁瀏覽器，並訪問 [http://127.0.0.1:8080](http://127.0.0.1:8080)。

#### b) 產生批次預測報告

如果您想一次性產生所有百大公司的預測報告，請在專案的根目錄下執行：

```bash
python src/batch_reporter.py
```

腳本執行完畢後，會在專案根目錄下生成一個名為 `百大個股預測_YYYY-MM-DD.docx` 的 Word 文件。

**注意**: 批次報告需要較長的執行時間（可能需要數十分鐘），因为它會對每一支股票重新進行數據獲取和模型訓練。
