# 台灣市值百大個股預測 Web App

這是一個 Flask Web 應用程式，旨在預測台灣市值百大上市公司的股價走勢。使用者可以從下拉式選單中選擇一支股票，應用程式將使用 XGBoost 模型進行訓練，並在網頁上以互動式圖表、預測數據表和模型輸入參數表，呈現未來 30 天的股價預測。

此外，專案還包含一個批次報告工具，可以一次性對所有百大公司進行預測，並將結果（包含圖表）匯出成一份 Word（.docx）文件。

## 專案特色

*   **Web 使用者介面**: 使用 Flask 和 Chart.js 打造，提供一個簡單直觀的介面來選擇股票並查看預測結果。
*   **動態市值排名**: 自動從台灣證券交易所 (TWSE) 獲取最新的公司資料和股價，計算出最新的市值百大公司列表。
*   **多源數據整合**:
    *   **歷史股價**: 使用 `yfinance` 獲取穩定且準確的每日歷史股價。
    *   **籌碼面數據**: 從 TWSE 公開 API 獲取**三大法人買賣超**和**融資融券**資料。
*   **豐富的特徵工程**: 結合了**技術指標**（如 MA、RSI）和**籌碼面指標**（如法人買賣超動量、券資比），以提高模型的預測能力。
*   **透明的模型輸入**: Web UI 會清楚地展示模型進行預測時所使用的最後一筆特徵數據，讓使用者了解判斷依據。
*   **批次報告功能**: 提供一個獨立的腳本 `src/batch_reporter.py`，可自動產生所有百大個股的預測報告。

## 程式邏輯說明

1.  **數據獲取**:
    *   `data_fetcher.py` 負責從 `yfinance` 和 `TWSE` API 獲取所有需要的原始數據。
    *   為了處理台股的上市（.TW）和上櫃（.TWO）市場，`get_historical_data` 函數會自動嘗試兩種股票代號後綴。
2.  **特徵工程**:
    *   `model.py` 中的 `create_features` 函數會將歷史股價、法人買賣超和融資融券數據進行整合。
    *   接著，它會計算多種衍生特徵，例如：
        *   **技術面**: 7日均線（MA7）、21日均線（MA21）、均線差（MA_diff）、相對強弱指數（RSI）、延遲特徵（lag features）。
        *   **籌碼面**: 5日法人平均買賣超（foreign_ma5）、法人買賣動量（foreign_momentum）、融資餘額變化率、融券餘額變化率、券資比。
3.  **模型訓練與預測**:
    *   `train_and_predict` 函數使用處理好的特徵數據來訓練一個 XGBoost 迴歸模型。
    *   為了預測未來 30 天，模型採用**迭代預測**的方式：預測第 N+1 天的價格，然後將這個預測結果作為一個新的特徵，用來預測第 N+2 天，依此類推。
4.  **結果輸出**:
    *   **Web App**: Flask 應用程式 (`app.py`) 將預測結果、歷史數據和最新的模型輸入特徵傳遞給 `index.html` 模板進行渲染。
    *   **批次報告**: `batch_reporter.py` 會調用相同的功能，但將結果逐一繪製成圖表，並使用 `python-docx` 寫入 Word 文件。

## 如何解讀回測準確度

回測是評估模型在過去數據上表現好壞的一種方法。`test_model.py` 中包含了回測的範例邏輯，主要依賴以下指標：

*   **MAPE (Mean Absolute Percentage Error，平均絕對百分比誤差)**:
    *   計算公式：`平均(|(實際值 - 預測值) / 實際值|) * 100%`
    *   **解讀**: MAPE 顯示了預測誤差佔實際價格的百分比。例如，MAPE 為 2.03% 意味著模型的預測平均偏離實際股價約 2.03%。**這個值越小，代表模型的價格預測越精準。**
    *   **優點**: 直觀，容易理解。
    *   **缺點**: 當實際值接近 0 時，此指標可能會變得極大或無意義。

在評估模型時，除了 MAPE，還應該觀察預測趨勢是否與實際趨勢大致相符。一個好的模型不僅要價格預測得準，更要能抓到股價上漲或下跌的大方向。

## 安裝與執行

### 1. 環境準備

*   建議使用 Python 3.9 或更新的版本。
*   建議在虛擬環境中安裝。

### 2. 安裝相依套件

```bash
pip install -r requirements.txt
pip install python-docx matplotlib
```

### 3. 執行方式

#### a) 啟動 Web 應用程式

在專案的根目錄下，執行以下指令：

```bash
python -m flask --app src.app run --port 8080
```

然後打開您的網頁瀏覽器，並訪問 [http://127.0.0.1:8080](http://127.0.0.1:8080)。

**注意**: 必須使用此指令來執行，這能確保 Python 直譯器將 `src` 目錄視為一個套件，從而正確處理模組之間的相對引用。

#### b) 產生批次預測報告

如果您想一次性產生所有百大公司的預測報告，請在專案的根目錄下執行：

```bash
python -m src.batch_reporter
```

腳本執行完畢後，會在專案根目錄下生成一個名為 `百大個股預測_YYYY-MM-DD.docx` 的 Word 文件。

**注意**:
1.  **執行方式**: 必須使用 `-m` 參數來執行，這能確保 Python 直譯器將 `src` 目錄視為一個套件，從而正確處理模組之間的相對引用。
2.  **執行時間**: 批次報告需要較長的執行時間（可能需要數十分鐘），因为它會對每一支股票重新進行數據獲取和模型訓練。
