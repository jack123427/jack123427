
# 附錄 C：實用公式與計算 (Appendix C: Useful Formulas & Calculations)

本書盡量避免了複雜的數學運算，以概念性的理解為主。然而，在音響系統的設計與調校過程中，掌握一些基礎的公式和計算方法，能幫助您更精確地預測和診斷問題。本附錄匯集了一些在聲學和電子學中最常用到的實用公式。

---

## 1. 聲學相關公式 (Acoustics Formulas)

### 波長 (Wavelength, λ)

計算一個特定頻率的聲波在空氣中的波長。

-   **公式**:
    `λ = c / f`

-   **參數**:
    *   `λ` (Lambda): 波長，單位為米 (m)。
    *   `c`: 空氣中的聲速，在室溫下約為 **344 m/s**。
    *   `f`: 聲音的頻率，單位為赫茲 (Hz)。

-   **範例**: 計算 100 Hz 低頻的波長。
    `λ = 344 / 100 = 3.44 米`
    (這意味著要有效吸收 100 Hz 的低頻，吸音材料的厚度需要與這個尺度相關，解釋了為何低頻處理如此困難。)

### 房間模式（軸向模式）計算 (Room Mode Calculation - Axial)

計算一個矩形房間中，由兩面平行牆壁產生的、能量最強的軸向駐波頻率。

-   **公式**:
    `f = (n * c) / (2 * D)`

-   **參數**:
    *   `f`: 駐波的基頻及其諧波頻率 (Hz)。
    *   `n`: 模式的階數，為正整數 (1, 2, 3, ...)。`n=1` 為最低階的基頻。
    *   `c`: 空氣中的聲速 (約 344 m/s)。
    *   `D`: 房間的尺寸（長、寬或高），單位為米 (m)。

-   **範例**: 計算一個長 5 米的房間的第一階（`n=1`）長度軸向模式頻率。
    `f = (1 * 344) / (2 * 5) = 34.4 Hz`
    (這意味著在 34.4 Hz，以及其倍頻 68.8 Hz, 103.2 Hz...，這個房間的長度方向上會產生強烈的駐波。)

## 2. 分貝 (Decibel, dB) 相關公式

### 聲壓級 (Sound Pressure Level, dB SPL)

計算聲壓相對於人類聽覺閾值的 dB 等級。

-   **公式**:
    `dB SPL = 20 * log10(P / P_ref)`

-   **參數**:
    *   `P`: 被測量的聲壓，單位為帕斯卡 (Pa)。
    *   `P_ref`: 參考聲壓，即人類聽覺閾值，固定為 **20 微帕斯卡 (μPa)** 或 `2 * 10^-5 Pa`。

### 功率變化 (Power Change)

計算功率變化量對應的 dB 值。

-   **公式**:
    `dB = 10 * log10(P2 / P1)`

-   **參數**:
    *   `P2`: 新的功率值。
    *   `P1`: 原始的功率值。

-   **範例**: 擴大機功率從 50 瓦增加到 100 瓦，增加了多少 dB？
    `dB = 10 * log10(100 / 50) = 10 * log10(2) ≈ 3.01 dB`
    (**結論：功率增加一倍，等於 +3 dB。**)

### 電壓/聲壓變化 (Voltage/Pressure Change)

計算電壓或聲壓變化量對應的 dB 值。

-   **公式**:
    `dB = 20 * log10(V2 / V1)`

-   **參數**:
    *   `V2`: 新的電壓或聲壓值。
    *   `V1`: 原始的電壓或聲壓值。

-   **範例**: 聲壓增加一倍，增加了多少 dB？
    `dB = 20 * log10(2 / 1) = 20 * log10(2) ≈ 6.02 dB`
    (**結論：電壓或聲壓增加一倍，等於 +6 dB。**)

## 3. 電子學相關公式 (Electronics Formulas)

### 歐姆定律 (Ohm's Law)

描述電壓、電流和電阻之間關係的基礎定律。

-   **公式**:
    *   `V = I * R`
    *   `I = V / R`
    *   `R = V / I`

-   **參數**:
    *   `V`: 電壓 (Volts)。
    *   `I`: 電流 (Amperes)。
    *   `R`: 電阻 (Ohms)。

### 電功率 (Electrical Power)

計算電路中的功率。

-   **公式**:
    *   `P = V * I`
    *   `P = I² * R`
    *   `P = V² / R`

-   **參數**:
    *   `P`: 功率 (Watts)。
    *   `V`, `I`, `R` 同上。

-   **範例**: 一台擴大機在 8 歐姆的揚聲器上輸出了 20 伏特的電壓，此時的輸出功率是多少？
    `P = (20)² / 8 = 400 / 8 = 50 瓦`

### 阻尼因數 (Damping Factor)

計算擴大機對揚聲器的控制能力。

-   **公式**:
    `DF = Z_load / Z_out`

-   **參數**:
    *   `DF`: 阻尼因數（無單位）。
    *   `Z_load`: 揚聲器的額定阻抗 (例如 8 Ω)。
    *   `Z_out`: 擴大機的輸出阻抗 (通常遠小於 1 Ω)。

-   **範例**: 一台擴大機的輸出阻抗為 0.05 Ω，驅動一個 8 Ω 的揚聲器，其阻尼因數是多少？
    `DF = 8 / 0.05 = 160`

---
**免責聲明**：這些公式為簡化的理想模型。在現實世界中，揚聲器阻抗是隨頻率變化的複數，聲學環境也遠比空房間複雜。但這些基礎計算，足以為您的音響設計與分析提供一個堅實的科學起點。
