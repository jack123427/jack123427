
# 第五章：訊源：一切的開端 (Chapter 5: The Source: Where It All Begins)

音響系統的聲音品質，遵循著「垃圾進，垃圾出」(Garbage In, Garbage Out) 的基本原則。無論後端的擴大機和揚聲器多麼優秀，它們都無法還原出訊源一開始就丟失的資訊。因此，選擇一個高品質的**訊源 (Source)**，是打造一套成功音響系統的第一步，也是最關鍵的一步。本章將介紹兩大主流的訊源類型：歷史悠久且充滿魅力的類比訊源，以及現代高解析度數位音訊的主力——數位訊源。

## 5.1 類比訊源：黑膠唱盤的結構與調校 (Analog Sources: The Structure and Calibration of Turntables)

在數位浪潮席捲全球之後，黑膠唱片 (Vinyl) 卻奇蹟般地迎來了復興。許多人著迷於它溫暖、真實的音色，以及充滿儀式感的播放過程。然而，要讓黑膠唱盤發出好聲音，需要對其機械結構有深入的了解和精心的調校。

一個黑膠唱盤主要由以下幾個部分組成：

1.  **底座 (Plinth)**：唱盤的基座，其主要作用是提供穩定性，並抑制來自外部（如腳步聲）和內部（如馬達）的振動。高品質的底座通常使用高密度、高阻尼的材料製成。

2.  **轉盤 (Platter)**：放置唱片的盤面。一個理想的轉盤應該具備高質量和高慣性，以確保轉速的穩定（稱為**抗抖動 Jitter** 和**抗飄移 Wow and Flutter**）。材質從壓克力、金屬到複合材料都有。

3.  **馬達 (Motor)**：驅動轉盤旋轉的動力來源。常見的驅動方式有**皮帶驅動 (Belt Drive)** 和**直接驅動 (Direct Drive)**。皮帶驅動透過一條橡膠皮帶連接馬達與轉盤，可以有效隔離馬達振動；直接驅動則將馬達直接整合在轉盤下方，提供更高的扭力和更精準的轉速控制。

4.  **唱臂 (Tonearm)**：負責承載唱頭，並使其以精確的角度和壓力，穩定地循著唱片溝槽的軌跡運動。唱臂的設計是一門精密的學問，需要考慮有效長度、循軌誤差、軸承摩擦力等諸多因素。

5.  **唱頭 (Cartridge)**：這是將唱片溝槽中的微觀機械振動，轉換為微弱電氣訊號的關鍵元件，可以說是唱盤的「靈魂」。唱頭內的唱針 (Stylus) 在溝槽中振動，帶動磁鐵或線圈運動，從而根據電磁感應原理產生音訊訊號。
    *   **動磁式 (Moving Magnet, MM)**：磁鐵隨著唱針運動，線圈固定。輸出電壓較高，價格相對親民，且唱針可替換，是入門者的好選擇。
    *   **動圈式 (Moving Coil, MC)**：線圈隨著唱針運動，磁鐵固定。輸出電壓非常低，需要搭配專用的**唱頭放大器 (Phono Stage)** 或**升壓器 (Step-up Transformer)**。MC 唱頭通常擁有更好的高頻延伸和動態表現，是進階玩家的首選。

### 黑膠唱盤的關鍵調校 (Essential Turntable Adjustments)

要讓唱頭從溝槽中拾取最準確的資訊，以下幾項調校至關重要：

-   **水平 (Leveling)**：必須使用水平儀，確保唱盤底座和轉盤本身處於絕對水平的狀態。
-   **針壓 (Tracking Force)**：唱針施加於唱片溝槽的垂直壓力。過輕會導致聲音飄忽、循軌不穩；過重則會磨損唱片和唱針。需根據唱頭原廠建議，使用專用針壓計進行精確設定。
-   **抗滑 (Anti-skating)**：由於唱臂的幾何結構，循軌時會產生一個指向中心軸的內滑力。抗滑設定的作用是施加一個反向的外張力，以抵銷內滑力，確保唱針在溝槽兩側的壓力均等，避免左右聲道不平衡和失真。
-   **方位角 (Azimuth)**：從正面看，確保唱針垂直於唱片表面。不正確的方位角會導致左右聲道的串音 (Crosstalk) 增加，影響立體聲分離度。
-   **垂直循軌角 (Vertical Tracking Angle, VTA)**：從側面看，唱臂在播放時應大致與唱片表面平行。VTA 會影響聲音的音調平衡，是相對進階的微調選項。

## 5.2 數位訊源：CD播放機、音樂串流機、DAC (Digital Sources: CD Players, Music Streamers, DACs)

數位訊源是當今音響系統的主流。它們將儲存在實體媒介（如 CD）或數位檔案中的 0 與 1，轉換為類比訊號。

### CD 播放機 (CD Player)

傳統的 CD 播放機是一體化的解決方案，內部包含了三個主要部分：
1.  **轉盤機構 (Transport)**：負責讀取 CD 上的數位資料。一個穩定、避震良好的轉盤機構是準確讀取數據的基礎。
2.  **數位類比轉換器 (DAC)**：將讀取出的 PCM 數位訊號轉換為類比訊號。
3.  **類比輸出級 (Analog Output Stage)**：將 DAC 輸出的微弱類比訊號進行緩衝和放大，以便送入擴大機。

隨著技術發展，許多高階設計將 CD 轉盤機構和 DAC 分離成兩台獨立的機器，透過數位線材（如同軸、光纖）連接，以減少內部電磁干擾，追求極致的性能。

### 音樂串流機 (Music Streamer / Network Player)

音樂串流機是為現代高解析度串流和本地檔案播放而生的訊源。它就像一台專為音訊優化的電腦，具備網路連接功能，可以：
-   **播放串流服務**：直接存取 Tidal, Qobuz, Spotify, Apple Music 等平台上的海量音樂資源。許多高階服務提供 CD 品質甚至更高解析度的無損串流。
-   **播放本地音樂庫**：透過網路，讀取並播放儲存在您家中電腦或網路硬碟 (NAS) 上的音樂檔案。

一台好的串流機，其優勢在於擁有設計精良的軟體介面（易於操作和管理音樂庫）和專為音訊最佳化的硬體（低噪音的電源供應、穩定的網路接收、優秀的數位訊號輸出）。

### 數位類比轉換器 (DAC - Digital-to-Analog Converter)

DAC 是所有數位訊源的**共同核心**。無論是 CD 播放機、串流機，甚至是您的電腦、手機，內部都有 DAC 晶片。然而，專用的**外接式 DAC (External DAC)** 提供了遠超內建晶片的性能和連接彈性。

**為什麼需要一台外接式 DAC？**
-   **卓越的性能**：獨立 DAC 擁有更好的電源供應、更精準的時脈系統和更發燒的類比輸出電路，能最大限度地降低噪音和時基誤差，帶來更乾淨、更精準的聲音。
-   **統一的音訊中樞**：現代 DAC 通常配備多種數位輸入端子（USB, 同軸, 光纖, AES/EBU），可以將您所有的數位設備（電腦、電視、遊戲機、CD 轉盤）全部接入，共用其高品質的轉換線路，成為整個系統的數位音訊中樞。
-   **支援最新格式**：外接 DAC 通常能支援最新的高解析度 PCM (如 32-bit/768kHz) 和 DSD 格式，確保您的系統不會過時。

在當今的音響系統中，一個常見且高效的組合是：**電腦/串流機（作為純數位轉盤） + 高品質外接式 DAC**。這種組合將數位數據處理和敏感的類比轉換過程徹底分離，是追求高音質的明智選擇。
