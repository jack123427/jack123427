
# 第四章：主動式電子分音器 (Chapter 4: Active Crossovers)

在傳統的音響系統中，分音的任務是由揚聲器內部、擴大機之後的**被動分音器**來完成的。然而，越來越多的高階音響、專業監聽系統和 DIY 愛好者，開始青睞一種更精準、更靈活的方案——**主動式分音 (Active Crossover)**。主動式分音器是一個獨立的電子設備，它在**前級之後、後級之前**，對微弱的線路電平 (Line Level) 訊號進行分頻。分頻後的高、低頻訊號，再被送入各自**獨立的後級放大器**，分別驅動對應的高、低音單體。這種架構被稱為**電子分音 (Bi-amping / Multi-amping)** 系統。本章將帶您深入主動式分音的核心——濾波器電路，並最終實作一台經典的 Linkwitz-Riley 電子分音器。

## 4.1 濾波器拓撲：Butterworth, Linkwitz-Riley, Bessel 的特性比較

主動式濾波器的「性格」，由其**拓撲 (Topology)** 決定。不同的拓撲，在分頻點附近的振幅響應、相位響應和暫態響應上，有著截然不同的表現。

### 巴特沃斯濾波器 (Butterworth Filter)
-   **特性**：在其通帶 (Pass-band) 內，具有**最平坦的振幅響應**，被譽為「最大平坦濾波器」。
-   **問題**：當您將一個 Butterworth 高通和一個 Butterworth 低通濾波器在分頻點疊加時，由於兩個濾波器在分頻點處各有 -3dB 的衰減，它們的聲學能量疊加後（同相時），會在分頻點產生一個 **+3dB 的突起**。此外，它的相位響應變化較為劇烈。
-   **應用**：因其在分頻點的能量突起，較少被直接用於高保真揚聲器分音。

### 貝塞爾濾波器 (Bessel Filter)
-   **特性**：具有**最線性、最平順的相位響應**，意味著它對訊號引入的群延遲 (Group Delay) 在通帶內是恆定的。這使得它擁有**最好的暫態響應**，聲音聽起來乾淨、快速、脈衝還原度最高。
-   **問題**：它的振幅響應滾降斜率，是所有拓撲中最為平緩的，這意味著高、低音單體之間的頻率重疊區會非常寬。

### 林奎茨-瑞利濾波器 (Linkwitz-Riley, LR)
-   **特性**：這是在高保真揚聲器分音設計中，**應用最廣泛、最受推崇的拓撲**。它並不是一個全新的類型，而是由**兩個完全相同的 Butterworth 濾波器串聯**而成。
-   **關鍵優勢**：一個二階 (12dB/oct) 的 LR 濾波器，是由兩個一階 (6dB/oct) 的 Butterworth 濾波器串聯構成。其結果是，在分頻點 `fc` 處，高通和低通濾波器的輸出都正好衰減了 **-6dB**。
    -   當這兩個 -6dB 的訊號在揚聲器端進行聲學疊加時，其總和的能量響應將會是**一條完美的平直線**，沒有任何峰谷。
    -   二階 LR 濾波器 (LR2)，其高、低通輸出之間有 180° 的相位差，因此需要將**高音單體的極性反接**。
    -   四階 LR 濾波器 (LR4, 24dB/oct)，其高、低通輸出之間有 360° (即 0°) 的相位差，可以**同相連接**。
-   **結論**：由於其完美的聲學疊加特性，**Linkwitz-Riley 濾波器（特別是四階 LR4）** 成為了主動和被動分音設計的業界標準。

## 4.2 Sallen-Key 濾波器電路設計

Sallen-Key 拓撲是一種非常經典、簡單且高效的**主動式濾波器**實現方式。僅需使用一個 Op-Amp、兩個電阻和兩個電容，就能輕鬆地搭建出一個二階 (12dB/oct) 的高通或低通濾波器。

-   **工作原理**：它巧妙地利用 Op-Amp 搭建的電壓隨耦器（增益為1）和負回授網路，來模擬出電感 (L) 的行為，從而避免了在主動濾波器中使用體積巨大且昂貴的真實電感器。
-   **設計公式 (Q=0.707 的 Butterworth 段)**：
    *   **二階低通濾波器 (Low-Pass)**：
        *   `fc = 1 / (2 * π * R * C)`
        *   (條件: R1=R2=R, C1=C2=C)
    *   **二階高通濾波器 (High-Pass)**：
        *   `fc = 1 / (2 * π * R * C)`
        *   (條件: R1=R2=R, C1=C2=C)

-   **實現 Linkwitz-Riley (LR2)**：如前所述，一個 LR2 濾波器是由兩個 Butterworth 濾波器串聯而成。因此，我們只需要將**兩個完全一樣的 Sallen-Key 一階 (6dB/oct) 濾波器電路前後串接起來**，就能得到一個完美的 LR2 二階 (12dB/oct) 濾波器。

## 4.3 狀態變數濾波器與常數 Q 值設計 (State Variable Filter)

狀態變數濾波器 (SVF) 是一種更為先進和靈活的主動濾波器拓撲。它通常使用 2-3 個 Op-Amp，但其最大的優點是：
-   **同時輸出**：一個 SVF 電路可以**同時提供低通 (LP)、高通 (HP) 和帶通 (BP)** 三種濾波器輸出。
-   **獨立控制**：可以獨立地調整濾波器的**中心頻率 (Frequency)** 和 **Q 值**，而不會相互影響。這使得它在等化器和合成器設計中非常受歡迎。

在電子分音器設計中，雖然 Sallen-Key 更為簡潔，但 SVF 提供了更高的設計自由度和精度。

## 4.4 [實作專案] 打造一台二音路 Linkwitz-Riley 24dB/oct 電子分音器

這個專案將打造一台高性能的立體聲二音路電子分音器，採用業界標準的四階 (24dB/oct) Linkwitz-Riley 拓撲。這意味著我們需要將**兩個二階 (12dB/oct) Sallen-Key 濾波器串聯**起來，以構成一個四階濾波器。

-   **設計目標**：
    *   立體聲輸入，立體聲高通輸出，立體聲低通輸出。
    *   分頻點 (Crossover Frequency)：可選，此處以 **2.5 kHz** 為例。
    *   拓撲：四階 Linkwitz-Riley (LR4)。
    *   供電：使用我們在第二章製作的 `+/-15V` 線性電源。

-   **電路結構**：
    1.  **輸入緩衝級**：每個聲道的輸入訊號，首先經過一個 Op-Amp 電壓隨耦器，為後級的濾波器網路提供一個低阻抗的訊號源。
    2.  **高通濾波級**：由**兩個**二階 Sallen-Key 高通濾波器串聯而成。
    3.  **低通濾波級**：由**兩個**二階 Sallen-Key 低通濾波器串聯而成。
    4.  **輸出級**：每個輸出端（高通/低通）可以選擇性地增加一個輸出緩衝級。

-   **元件計算 (以 2.5 kHz 分頻點為例)**：
    *   使用 `fc = 1 / (2 * π * R * C)` 公式。
    *   我們可以先選定一個方便取得的電容值，例如 `C = 4.7 nF (0.0047 μF)`。
    *   然後計算所需的電阻值 `R = 1 / (2 * π * fc * C)`
    *   `R = 1 / (2 * 3.14159 * 2500 * 4.7 * 10^-9) ≈ 13,560 Ω`
    *   我們可以選用最接近的標準電阻值，例如 **13.5 kΩ**，並使用高精度的金屬膜電阻。

-   **製作步驟**：
    1.  **[電路圖]** 繪製一個完整的單聲道電路圖，包含輸入緩衝、串聯的兩級低通濾波器、串聯的兩級高通濾波器。整個電路需要多個雙 Op-Amp IC。
    2.  **元件選擇**：選擇低噪音、高性能的音訊 Op-Amp（如 NE5532, OPA2134）。所有電阻使用 1% 精度的金屬膜電阻，所有電容使用高精度的薄膜電容（如 WIMA MKP）。
    3.  **PCB 佈局與製作**：精心設計 PCB，確保左右聲道對稱，電源路徑清晰，訊號地與電源地透過星型接地方式連接。
    4.  **測試**：組裝完成後，先不上電。使用萬用表的電阻檔，檢查電源輸入端是否有短路。確認無誤後，連接 `+/-15V` 電源。測量每個 Op-Amp 的電源腳，確保供電正常。可以使用電腦上的虛擬示波器軟體和聲卡，向輸入端輸入掃頻訊號，並測量高、低通輸出端的頻率響應，驗證分頻點和滾降斜率是否符合設計預期。

-   **系統連接**：
    `訊源 -> 前級 -> [本專案的電子分音器] -> 兩台立體聲後級 -> 高/低音單體`

**本章小結**

主動式電子分音是釋放揚聲器單體全部潛力的終極武器。在本章，我們深入比較了 Butterworth、Bessel 和 Linkwitz-Riley 這三種主流濾波器拓撲的特性，並確立了 LR 濾波器因其完美的聲學疊加特性而成為業界標準。我們學習了如何使用經典的 Sallen-Key 電路來實現主動濾波，並最終透過一個完整的四階 LR 電子分音器專案，將理論付諸實踐。當您完成了這個專案，您就擁有了一套極其靈活、精準的揚聲器管理系統。接下來，我們將進入音響系統的「肌肉」部分——功率放大器電路。
