
# 第三章：前級放大器設計 (Chapter 3: Preamplifier Design)

前級放大器 (Preamplifier) 是音響系統的控制中心與神經中樞。它看似簡單，卻肩負著幾項至關重要的任務：接收來自不同訊源的微弱訊號、進行無失真的音量控制、提供初步的電壓放大，並最終以一個低阻抗的、強健的訊號，去驅動後級放大器。一個設計精良的前級，應該像一塊純淨無瑕的玻璃，在忠實傳遞訊號的同時，不添加任何自身的音染或噪音。本章將帶您深入前級放大器的核心電路，從經典的電晶體放大級到現代的運算放大器應用，並最終動手打造一台屬於您自己的高保真前級。

## 3.1 核心放大級：單電晶體 vs. 運算放大器設計 (Core Gain Stage: Single Transistor vs. Op-Amp Design)

放大級 (Gain Stage) 是前級的心臟，負責將輸入訊號的電壓進行提升。其設計理念主要有兩大流派：

### 分離式電晶體設計 (Discrete Transistor Design)

使用獨立的電晶體（或其他主動元件如 JFET、MOSFET）來搭建放大電路。這種設計給予了設計者最大的自由度，可以精確控制電路的每一個細節和工作點。
-   **JFET 場效應電晶體 (Junction Field-Effect Transistor)**：JFET 是許多發燒友在設計前級時的最愛。它是一種**電壓控制器件**（與 BJT 的電流控制不同），具有極高的輸入阻抗，對前端訊源的負載極小。其失真特性以偶次諧波為主，聽感上被認為比 BJT 更為溫暖、更具「真空管味」。
-   **A 類單端放大級 (Single-Ended Class A)**：這是一種最簡潔、最經典的 JFET 放大電路。只使用一個 JFET 負責對整個訊號波形（正負半週）進行放大。由於電晶體始終工作在線性區，不存在交越失真，聲音純淨自然。其缺點是增益通常不高，且需要精心選擇元件進行配對和偏壓設定。

### 運算放大器 (Op-Amp) 設計

使用高度整合的運算放大器 IC 作為放大核心。這是一種現代、高效且極易獲得高性能的設計方式。
-   **優點**：
    *   **高性能**：現代的音訊專用 Op-Amp（如 OPA134, LME49720, NE5532 等）內部已經包含了經過優化的多級差動放大電路，擁有極低的失真、極低的噪音和極高的頻寬。
    *   **設計簡單**：只需遵循黃金法則，搭配極少數的外部電阻和電容，就能輕鬆實現一個性能卓越的放大級。增益由外部電阻精確決定，無需複雜的偏壓計算。
    *   **一致性好**：IC 製造工藝確保了每一顆 Op-Amp 的性能都高度一致。
-   **電路拓撲**：通常採用我們在第一章學到的**非反相放大電路**，因為它具有很高的輸入阻抗，不會對前端的音量控制器造成負載。

`[圖解：一個完整的使用 Op-Amp 的前級放大級電路圖。訊號從音量電位器進入 Op-Amp 的非反相端 (+)，反相端 (-) 透過回授電阻 Rf 和接地電阻 Rin 構成負回授網路，決定了增益 (Gain = 1 + Rf / Rin)。並標示出電源端的去耦電容。]`

## 3.2 音量控制的藝術：電位器、級進式衰減器與數位控制 (The Art of Volume Control)

音量控制是前級最關鍵的功能，其品質直接影響到聲音的透明度和左右聲道的平衡性。

### 傳統電位器 (Potentiometer)

這是一個三端點的可變電阻，也是最常見的音量控制器。
-   **工作原理**：訊號從一端輸入，接地端接地，中心滑臂作為輸出。轉動旋鈕時，滑臂在碳膜電阻軌道上滑動，改變了輸出訊號的分壓比，從而控制音量。
-   **缺點**：
    *   **聲道不平衡**：普通的碳膜電位器，其左右聲道的電阻軌跡很難做到完全一致，尤其在低音量時，容易出現左右聲道音量大小不一的問題。
    *   **磨損與噪音**：長時間使用後，碳膜會磨損，轉動時可能產生「沙沙」的噪音。
-   **高品質選擇**：**ALPS** 品牌的藍色或黑色外殼電位器，因其優良的聲道一致性和耐用性，成為音響 DIY 的標準配備。

### 級進式衰減器 (Stepped Attenuator)

這是追求極致性能的發燒級選擇。它不使用連續滑動的碳膜，而是用一個多檔位的旋轉開關，來切換一串由**高精度固定電阻**組成的分壓網路。
-   **優點**：
    *   **完美的聲道平衡**：由於左右聲道都使用誤差極小（例如 0.1%）的精密電阻，因此在任何音量格數下，聲道平衡度都趨於完美。
    *   **高透明度**：訊號只流經兩個固定電阻，路徑最短，音染最低。
    *   **手感明確**：轉動時有清晰的檔位感。
-   **缺點**：**成本高昂、體積巨大、音量格數固定**。

### 數位控制類比音量 (Digitally Controlled Analog Volume)

使用專門的音量控制 IC（如 Muses PGA2311），它在晶片內部整合了精密的電阻網路和類比開關，可以用微控制器（如 Arduino）發送的數位訊號來控制音量衰減，兼具了級進式的精度和數位控制的便利性。

## 3.3 輸入選擇與緩衝級 (Input Selection and Buffering)

-   **輸入選擇 (Input Selection)**：通常使用一個高品質的**機械式旋轉開關**或**繼電器 (Relay)** 陣列來切換不同的輸入訊源。繼電器切換可以讓訊號路徑最短，避免訊號線在機箱內長距離走線，是更高階的設計。
-   **緩衝級 (Buffer Stage)**：一個好的前級，其輸出級應該是一個**緩衝器**。緩衝器是一個**增益為 1（無電壓放大）**的放大器，它具有**極高的輸入阻抗**和**極低的輸出阻抗**。它的作用就像一個「訊號啦啦隊」，它不會改變訊號的電壓，但會為其提供強大的**電流驅動能力**，確保訊號在送往後級的長訊號線中，不會因為線材的電容負載而發生高頻衰減。使用 Op-Amp 搭建的**電壓隨耦器 (Voltage Follower)** 是最簡單、最有效的緩衝級電路。

## 3.4 [實作專案] 設計並製作一台發燒級的高保真 Op-Amp 前級

這個專案將結合本章所學的知識，打造一台性能卓越、媲美廠機的前級。我們將使用在第二章製作的 `+/-15V` 線性電源。

-   **設計目標**：
    *   三組 RCA 輸入選擇。
    *   ALPS RK27 高品質音量電位器。
    *   基於高性能音訊 Op-Amp 的核心放大級。
    *   直流耦合 (DC Coupled) 設計，訊號路徑無任何耦合電容。
    *   獨立的 Op-Amp 緩衝輸出級。

-   **元件清單**：
    *   音訊 Op-Amp：2 x LME49720 (雙 Op-Amp IC) 或同等級產品。
    *   IC 插座：2 x 8-pin DIP 插座。
    *   電位器：1 x ALPS RK27 雙聯 50kΩ 對數型。
    *   電阻：若干高精度金屬膜電阻（用於設定增益）。
    *   電容：若干 WIMA 薄膜電容（用於電源去耦）。
    *   輸入選擇開關：1 x 雙刀三擲 (2P3T) 旋轉開關。
    *   RCA 端子、機箱、旋鈕、導線等。

-   **電路圖與製作步驟**：
    1.  **[電路圖]** 繪製完整的雙聲道前級電路圖。訊號路徑為：RCA 輸入 -> 旋轉開關 -> 音量電位器 -> 第一級 Op-Amp 非反相放大級（設定約 3-5 倍增益）-> 第二級 Op-Amp 電壓隨耦器（緩衝輸出級）-> RCA 輸出。
    2.  **PCB 佈局**：設計一塊合理的 PCB 電路板，注意左右聲道對稱，訊號路徑盡可能短，遠離電源變壓器。將每一級的電源去耦電容盡可能靠近 Op-Amp 的電源腳。
    3.  **焊接與組裝**：先焊接 IC 插座和所有被動元件，最後再插入脆弱的 Op-Amp IC。將電路板、開關、電位器、RCA 端子安裝到機箱上，並完成所有接線。
    4.  **測試**：在連接後級之前，先單獨為前級通電。使用萬用表的直流電壓檔，測量**輸出端**的**直流偏移 (DC Offset)**。這個值應該非常低，理想情況下應在 +/- 10mV 以內。如果偏移過大，應立即斷電檢查電路。確認無誤後，即可將其接入您的音響系統。享受您親手打造的、水晶般純淨的聲音！
